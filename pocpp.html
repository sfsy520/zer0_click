Cosmos signDoc.chainId mismatch broadcast PoC

This PoC asks imToken for a signature under the outer approved chain, but places another chain ID inside the actual Cosmos SignDoc. It then broadcasts the signed TxRaw to the target chain LCD.

Use a small funded test wallet. Default recipient is the same derived target-chain address, so the transfer is a self-transfer and the expected cost is mainly gas fee.
